# Happy Birthday, Jedy ❤️

A personal birthday surprise website with photos, video, and heartfelt message.

## Quick start (local)
1. Download the full package zip from the chat (it includes the optimized photos + video).
2. Extract and open `index.html` in any browser.

## Host on Vercel (recommended)
1. Go to [vercel.com/new](https://vercel.com/new)
2. Import the GitHub repo `SmgSmart/jedy-birthday-surprise`
3. Upload the media files (or use the single-file version)
4. Deploy — you will get a free public URL instantly.
